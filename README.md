# Pomodoro Planner

A lightweight in-browser Pomodoro timer that tracks completed focus sessions on a morning calendar from 8:00 AM to 12:00 PM.

## Getting started

Just open `index.html` in any modern browser. Session progress is stored in `localStorage`, so completed Pomodoros for the day will stay visible if you refresh the page.

## Features

- 25-minute Pomodoro timer with start, pause/resume, and reset controls.
- Automatic logging of completed sessions into hourly slots between 8 AM and noon.
- Visual morning calendar that displays how many Pomodoros were completed per hour block.
- Local persistence so your progress for the current day is preserved.
